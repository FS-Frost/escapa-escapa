# Escapa Escapa

A colorful pixel-art auto-scroller. You are a cute lavender cube: dodge obstacles across three lanes and reach the finish line.

Everything — sprites, backgrounds, font, sound — is generated by code with WebGL2 and Web Audio. No image or sound files.

**Play:** https://fs-frost.github.io/escapa-escapa/ (best on a phone in landscape)

## Run Locally

Requires Node.js 22+.

```
npm install
npm run dev       # http://localhost:5173 — also reachable from phones on the same network
npm run build     # production build in dist/
npm run preview   # serve the production build
```

Pushing to `main` deploys to GitHub Pages automatically (`.github/workflows/deploy.yml`).

## Controls

| Action | Touch / mouse | Keyboard |
|--------|---------------|----------|
| Jump to a lane | Tap that lane (anywhere on screen, even mid-jump) | — |
| Move up / down one lane | — | `↑` or `Space` / `↓` |
| Pause / Resume | ⏸ button | `P` or `Esc` |

Jumping from the bottom to the top lane is a single arc; obstacles in the middle lane can't hit you on the way.

## How to Play

1. Obstacles scroll in from the right across three lanes (top, mid, bottom).
2. Change lanes to avoid them. Each avoided obstacle earns **1 point × your current multiplier**.
3. Avoid 5 obstacles in a row to raise your multiplier: **×1 → ×2 → ×3 → ×4**.
4. At **100 points** the goal flag appears on the radar and arrives in about **30 seconds** while the pace speeds up.
5. Reach the goal to win.

## Obstacles

| Name | Lane(s) | Description |
|------|---------|-------------|
| Zombie | Bottom, Mid | Animated walking enemy |
| Spike | Bottom | Static sharp trap |
| Bat | Mid, Top | Sine-wave flying enemy |
| Ghost | Top | Translucent, sine-wave drifter |
| Pit | Bottom | Gap in the floor — be out of the bottom lane |
| Big M Orb | Any | Power-up: +1 HP (max 2) |

## Features

- **Tap-to-lane** touch control with smooth arcs and mid-jump retargeting
- **Radar strip** showing color-coded incoming hazards and the goal beacon
- **Combo multiplier** up to ×4 with popups
- **3 biomes** — City → Forest → Sky — with parallax and crossfades
- **Procedural pixel font**, crisp at any screen size
- **Synthesized audio** (Web Audio API) and **vibration** on supported phones
- **Achievements**, **top-5 high scores** with your name, and a daily best
- **Spanish / English**, auto-detected and switchable
- **Options** (from the main menu and pause): language, volume, mute, vibration, radar, reduce motion, fullscreen
- **Mobile-ready**: landscape layout with safe areas, rotate notice in portrait, auto-pause when the app is hidden or rotated

## Browser Compatibility

Requires WebGL2 and Web Audio: current Chrome, Edge, Firefox and Safari (desktop and mobile). Notes:

- Vibration works only where the Vibration API exists (Android browsers); the option is hidden on iOS.
- Fullscreen is unavailable on iPhone Safari; the button is hidden there.
